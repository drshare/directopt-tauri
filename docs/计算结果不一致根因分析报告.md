## 一、结论摘要

> **2026-08-31 更新（已实测证伪并修正）**
>
> 本报告第二节「远程实际使用 0~200 MW 择优范围」的推断**不成立**。
> 已在 V3.0 上实测：使用输入模板自带的 **1~500 MW** 范围、贝叶斯优化 100/20
> 直接实跑，得到的最优结果为风电 192.73 MW / 光伏 78.37 MW / 储能 45.48 MWh、
> 综合电价 0.235336 元/kWh，**与黄金基准完全一致**。
> 因此「范围被覆盖成 1~500」不是差异根因，V3.0 用的本来就是 1~500。
>
> 另：报告中「总评估次数/初始随机采样点数 = GA 代数/种群」的推测同样有误——
> V3.0 界面已无 GA 四项参数，这两项是**贝叶斯优化**参数（详见第三节）。
>
> 最新结论与完整数据见 `docs/V3.0-输出对比报告.md`。

**计算引擎本身完全正确，不一致的根因在输入参数传递环节。**

本地 Rust 计算引擎在使用与远程相同的参数时，输出结果与远程**精确一致**（浮点级对拍通过，见下文证据）。差异来源于：

1. **【主因】择优范围（Range）被输入模板覆盖**：上传 `inputtemplate_ldzl_3.0.xlsx` 后，范围被回填为 1~500 MW，而远程/黄金基准使用 0~200 MW（风电/光伏）、0~300 MWh（储能）。GA 使用固定随机种子，搜索空间变化导致初始种群与进化路径完全不同，收敛到不同最优点。
2. **【次因】GA 参数未从输入模板解析**：输入模板中的「总评估次数=100」「初始随机采样点数=20」被解析器跳过，本地使用默认值（40 代 / 100 种群）。远程可能使用这两个参数控制寻优迭代次数。
3. **【参考】curvetemplate 的 output Sheet 数据不可作为对比基准**：该 Sheet 中最优配置（风电 101.69 MW / 储能 179.25 MWh）与远程差异巨大，且逐时发电量全为 0、多个指标出现 `#DIV/0!`，属于未完成计算的模板残留。

### 2.3 GA 固定随机种子 + 搜索空间变化 = 不同结果

**GA 实现**（`src-tauri/src/compute/ga.rs`）：

```rust
const GA_SEED: u64 = 0x2026_0829_0001;  // 固定随机种子
// ...
let mut rng = StdRng::seed_from_u64(GA_SEED);
// 初始化种群：在 bounds 范围内随机生成
let mut pop: Vec<Genes> = (0..pop_size)
    .map(|_| random_individual(&mut rng, &bounds))
    .collect();
```

**因果链**：

1. 固定种子 `GA_SEED` 保证相同 `bounds` + 相同 `ga` 参数 → 完全相同的随机数序列 → 完全相同的初始种群 → 完全相同的进化路径 → 完全相同的最优解（测试 `ga_respects_bounds_and_improves` 验证了可复现性）
2. 当 `bounds` 从 `[0, 200000]` kW 变为 `[1000, 500000]` kW 时，`random_individual` 中 `rng.gen_range(bounds[i].0..=bounds[i].1)` 生成的初始个体完全不同
3. 初始种群不同 → 锦标赛选择的父代不同 → SBX 交叉的子代不同 → 高斯变异的方向不同 → 最终收敛到不同的最优点
4. 即使目标函数（综合电价）的全局最优不变，GA 在有限代数内找到的是**启发式局部最优**，搜索空间变化会显著影响找到哪个局部最优

**远程结果的佐证**：远程最优风电 = 192.73 MW，非常接近 200 MW 上界。如果远程使用 1~500 MW 范围，GA 很可能探索到 200 MW 以上的区域并找到不同（可能更优）的解。远程结果恰好落在 0~200 MW 范围内且接近上界，强烈暗示远程使用的搜索范围上界为 200 MW。

## 三、根因详解

### 根因 1（主因）：择优范围不一致

| 维度 | 远程/黄金基准 | 本地（上传输入模板后） |
|---|---|---|
| 风电范围 | 0 ~ 200 MW | 1 ~ 500 MW |
| 光伏范围 | 0 ~ 200 MW | 1 ~ 500 MW |
| 储能范围 | 0 ~ 300 MWh | 1 ~ 500 MWh |
| 范围上界/下界比 | 200x / 200x / 300x | 500x / 500x / 500x |

**影响机制**：
- GA 初始种群在 `[1000, 500000]` kW 范围内均匀分布，与 `[0, 200000]` kW 完全不同
- 固定种子下，随机数序列相同，但映射到不同区间后个体基因值完全不同
- 进化过程中，更宽的搜索空间意味着变异步长更大（`sigma = 0.1 * (bounds[i].1 - bounds[i].0)`），收敛行为不同
- 最终 GA 收敛到不同的局部最优点

**验证方法**：将本地择优范围手动改回 0~200 / 0~200 / 0~300，重新计算，结果应与远程一致（黄金测试已证明）。

---

### 根因 2（次因）：GA 参数未从输入模板解析

| 参数 | 输入模板值 | 本地实际使用值 | 远程可能使用值 |
|---|---|---|---|
| 总评估次数 | 100 | （忽略，使用 generations=40） | 可能作为 GA 代数=100 |
| 初始随机采样点数 | 20 | （忽略，使用 populationSize=100） | 可能作为初始种群=20 或拉丁超立方采样数 |

**影响机制**：
- 如果远程使用「总评估次数=100」作为 GA 代数，则远程进化 100 代 vs 本地 40 代，收敛程度不同
- 如果远程使用「初始随机采样点数=20」控制初始种群大小或采样策略，则初始种群分布不同
- 即使范围相同，GA 参数不同也会导致结果不同（但黄金测试证明范围 0~200 + GA 40代/100种群 恰好匹配远程，说明远程很可能也使用这些 GA 参数）

**代码位置**：
- `src/lib/fileParsers.ts` 第 14-45 行：`INPUT_LABEL_KEYS` 未包含「总评估次数」「初始随机采样点数」
- `src-tauri/src/compute/input_parse.rs` 第 16-47 行：同上
- `src/composables/useParams.ts` 第 43-46 行：GA 参数使用硬编码默认值

---

### 根因 3（参考）：output Sheet 残留数据误导

curvetemplate 文件中的 output Sheet 包含未完成计算的残留数据（最优配置 101.69/79.19/89.62/179.25），可能被误认为是「本地计算结果」。实际上：
- 该 Sheet 的逐时数据全空，说明仿真未执行
- 汇总指标大量为 0 或 `#DIV/0!`，说明经济性计算未完成
- 前 4 项最优配置可能来自旧版本软件或不同参数集的计算

**建议**：对比时应以应用实际运行后的结果为准，不以模板 output Sheet 为准。
