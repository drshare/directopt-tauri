## 四、B 层：寻优质量对比（统计性）

在**完全相同**的择优范围（1~500）与评估预算（100 次）下，两侧各自独立寻优：

| | 本地（约束贝叶斯优化） | V3.0 报告值 |
|---|---|---|
| 最优风电规模 | 208.49 MW | 192.73 MW |
| 最优光伏规模 | 78.09 MW | 78.37 MW |
| 最优储能容量 | 68.41 MWh | 45.48 MWh |
| **综合电价** | **0.234989 元/kWh** | **0.235336 元/kWh** |

本地结果比 V3.0 低 **0.000147 元/kWh（-0.15%）**。

两点说明：
1. 两者都是 100 次评估预算下的启发式结果，最优点不必相同；本地略优不代表精度更高，只说明未落入更差的局部解。
2. V3.0 自身的敏感性分析表显示，其报告最优点（0.235336）**并非其寻优过程中出现过的最好点**——同一张表里风电 +5% / +10% 两行的适应度为 0.234807 / 0.234702，均优于 0% 行的 0.235336。这从侧面说明 V3.0 的结果本身存在局部收敛。

## 五、算法口径的关键修正（本次变更要点）

### 5.1 V3.0 用的是贝叶斯优化，不是遗传算法

V2.2 说明书描述的是遗传算法（遗传代数 / 交叉概率 / 变异概率 / 种群大小）。而 V3.0 界面「算法参数」区**只有「总评估次数」「初始随机采样点数」两项**，软件自标注为「贝叶斯优化，测试中……」。旧版根因分析报告把这两项误判为 GA 的代数与种群大小。

### 5.2 适应度罚值：展示 0.98 / 寻优另计

V3.0 敏感性分析表中，不满足约束的方案适应度恒为 **0.98**（如风电 +15%/+20%/+25% 三行因弃电率超标均为 0.98）。

本项目据此拆成两个口径：
- **展示口径**（敏感性表）：不可行 → 固定 0.98，与 V3.0 完全一致
- **寻优口径**（优化器内部）：不可行 → 目标值 + 抬升量×违反量，保留违反程度信息，避免采集函数在常数平台上失去方向（初投资目标量级可达数万元，0.98 会小于可行解，直接用会误判）

### 5.3 约束贝叶斯优化（关键性能改进）

择优范围取 1~500 时，**可行域仅约 19%**（0~200 时为 81%）。20 个初始采样点里只有约 4 个可行，若把「目标 + 罚项」压成单一标量去拟合 GP，代理模型学到的主要是罚值悬崖，采集函数会被持续引向不可行区。

改造为分离建模：
- 目标 GP 拟合目标值
- 违反量 GP 拟合约束违反量，给出 P(可行) = Φ(−μ_v/σ_v)
- 采集函数 = gp_hedge(EI / LCB / PI) × P(可行)
- 预算后 25% 转入纯开发阶段

**效果**：同一算例最优综合电价 0.243553 → **0.234989**（改善 3.5%），由劣于 V3.0 变为优于 V3.0。
