## 敏感性曲线

### 风电容量变动敏感性曲线

- **X 轴**：变动比例（-25.0% ~ 20.0%）
- **Y 轴**：适应度值
- **趋势**：-25% ~ 10% 区间适应度缓慢下降（0.253 → 0.235），在 10% 附近达到最低；15% 起适应度跳升至 0.98（弃电率超标，约束违反惩罚），之后维持高位平台。

### 光伏容量变动敏感性曲线

- **X 轴**：变动比例（-25.0% ~ 20.0%）
- **Y 轴**：适应度值（0.235000 ~ 0.238000）
- **趋势**：随光伏规模增大，适应度单调下降至 10% 附近（约 0.23506），随后缓慢回升；全区间均满足所有约束，曲线呈浅 U 型，最优区间在 5% ~ 15%。

### 储能容量变动敏感性曲线

- **X 轴**：变动比例（-25.0% ~ 20.0%）
- **Y 轴**：适应度值（0.235300 ~ 0.235491）
- **趋势**：-25% ~ -15% 基本持平（约 0.23530），-10% 起随储能容量增大适应度单调缓慢上升；全区间满足所有约束，储能容量对适应度影响极小（波动范围 < 0.0002）。

## 电量平衡曲线

- **X 轴**：时序点（1 ~ 1429，含缩放滑块）
- **Y 轴**：电量（kW），范围 -200,000 ~ 200,000

**图例：**

| 颜色 | 含义 |
|---|---|
| 紫色 | 储能放电量 |
| 黄色 | 下网电量 |
| 红色 | 用户负荷 |
| 蓝色 | 储能充电量 |
| 绿色 | 余电上网电量 |

**特征：**
- 用户负荷（红色）持续为正，基线约 50,000 kW，日间有波动。
- 储能放电量（紫色）与下网电量（黄色）叠加覆盖负荷缺口。
- 储能充电量（蓝色，负值）与余电上网电量（绿色，负值）在新能源大发时段出现，峰值可达 -150,000 kW 以下。
- 底部附缩放滑块，支持局部时段放大查看。
